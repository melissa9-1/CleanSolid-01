01 / Los fundamentos

Principios para construir
con propósito.

Ideas sencillas que ayudan a que cada parte del sistema tenga un lugar y una razón de existir.

01 ◉

Responsabilidad única

Un módulo, una razón para cambiar. Mantén cada pieza enfocada en una tarea.

S · Single Responsibility
02 ↗

Abierto / cerrado

Extiende el comportamiento sin tener que modificar lo que ya funciona.

O · Open / Closed
03 ⌁

Sustitución de Liskov

Las implementaciones deben cumplir las expectativas de sus abstracciones.

L · Liskov Substitution
04 ⊞

Segregación de interfaces

Prefiere interfaces pequeñas y específicas antes que contratos demasiado amplios.

I · Interface Segregation
05 ⇢

Inversión de dependencias

Depende de abstracciones, no de detalles concretos de implementación.

D · Dependency Inversion
+ ✳

Código limpio

Nombres claros, funciones pequeñas y decisiones que se explican por sí mismas.

CL · Clean Code
